# seowon-client-api

서원대학교 e-campus(LMS) 연동을 위한 전문가용 TypeScript 클라이언트 라이브러리 및 CLI 도구입니다.

## 🌟 핵심 강점

- **완벽한 학습 재현**: 실제 사용자의 행동 패턴(Fiddler 로그 분석 기반)을 1:1로 모사하여 정밀한 학습 인증 자동화를 구현합니다.
- **견고한 모니터링**: 다양한 서버 응답 형식에 대응하는 실시간 진행률(%) 추출 로직을 갖추고 있으며, 주요 구간마다 시각적 알림을 제공합니다.
- **스마트 자료 추출**: 고해상도 MP4 영상 추출 및 다운로드, 강의실 공지/과제/자료실의 통합 조회를 지원합니다.
- **고도화된 CLI UX**: 입력 프롬프트가 밀리지 않는 정밀한 UI 제어와 실시간 명령어(`status`, `clear`, `stop`)를 제공합니다.

## 🚀 주요 기능

1. **학습 자동화 (ElearningSession)**
   - 45~75초 랜덤 딜레이를 통한 안정적 기록 전송.
   - 서버 응답 형식 변화에 강한 유연한 진행률 파싱 기술 적용.
   - 학습 이력 상세 조회 연동 및 종료 패킷(`exitStudy`) 전송 보장.
2. **미디어 관리**
   - e러닝 차시별 실제 MP4 URL 분석 (Base64 fallback 지원).
   - 진행률 표시를 포함한 스트림 기반 영상 다운로드.
3. **통합 강의실 조회**
   - 수강 중인 모든 과목의 공지사항, 과제, 강의자료 통합 파싱.

## 🛠 기술 스택

- **Language**: TypeScript
- **Network**: Axios, tough-cookie
- **Scraping**: Cheerio
- **CLI Control**: Readline (Interface control)

## 📦 시작하기

1. **설치**
   ```bash
   npm install
   ```
2. **설정**
   `.env` 파일에 `SEOWON_ID`, `SEOWON_PASSWORD`를 입력합니다.
3. **실행**
   ```bash
   node prompt-client.js
   ```

## 🖥 CLI 명령어 가이드 (학습 중)

- **status**: 현재 진행률 및 상태 즉시 확인.
- **clear**: 로그 화면을 정리하고 입력창 유지.
- **stop**: 학습을 중단하고 종료 패킷 전송 후 메뉴로 복귀.
