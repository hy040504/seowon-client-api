# seowon-client-api

서원대학교 e-campus(LMS) 연동을 위한 TypeScript 클라이언트 라이브러리 및 CLI 도구입니다.

## 🚀 핵심 기능

- **정밀한 학습 인증 자동화**: Fiddler 로그 분석을 통해 실제 사용자의 시청 패턴(45~75초 랜덤 딜레이, 상세 이력 조회, 종료 패킷 전송 등)을 완벽히 재현합니다.
- **강의 자료 추출 및 다운로드**: 주차별 e러닝 목록 조회, 고해상도 MP4 URL 추출 및 자동 다운로드를 지원합니다.
- **강의실 통합 관리**: 수강 중인 모든 과목의 공지사항, 과제, 강의자료실 목록을 한눈에 확인할 수 있습니다.
- **고급 CLI 인터페이스**: 인터랙티브 메뉴를 통해 모든 기능을 코드 수정 없이 즉시 사용할 수 있으며, 실시간 학습 상태를 모니터링할 수 있습니다.

## 🛠 기술 스택

- **Runtime**: Node.js (20+)
- **Language**: TypeScript
- **Network**: Axios, tough-cookie (CookieJar 관리)
- **Parsing**: Cheerio (HTML Scraping)
- **Testing**: Vitest

## 📦 설치 및 실행

1. **의존성 설치**
   ```bash
   npm install
   ```

2. **환경 변수 설정**
   `.env.example` 파일을 복사하여 `.env` 파일을 생성하고 계정 정보를 입력합니다.
   ```env
   SEOWON_ID=your_id
   SEOWON_PASSWORD=your_password
   ```

3. **CLI 도구 실행**
   ```bash
   node prompt-client.js
   ```

## 🖥 CLI 메뉴 안내

1. **로그인**: 세션을 초기화하고 쿠키를 저장합니다.
2. **과목 목록**: 현재 수강 중인 과목과 강의실 코드를 확인합니다.
3. **강의실 자료**: 특정 과목의 공지/과제/자료를 통합 조회합니다.
4. **e러닝 목록 조회**: 주차별 강의 차시 정보를 확인합니다.
5. **e러닝 MP4 URL 추출**: 직접 시청 가능한 MP4 주소를 얻습니다.
6. **e러닝 MP4 다운로드**: 강의 영상을 로컬 파일로 저장합니다.
11. **e러닝 자동 시청 (학습 인증)**: 정해진 시간만큼 자동으로 학습 이력을 갱신합니다.

## 📁 프로젝트 구조

```text
src/
├── ecampus/
│   ├── login.ts      # 메인 클라이언트 및 인증
│   ├── elearning.ts  # 학습 자동화 및 세션 관리
│   ├── classroom.ts  # 강의실 데이터 파싱
│   └── courses.ts    # 과목 목록 파싱
├── index.ts          # 외부 노출 API
prompt-client.js      # 인터랙티브 CLI 도구
```

## ⚠️ 주의사항

- 이 도구는 교육 및 연구 목적으로 제작되었습니다.
- 실제 학습 인증 기능 사용 시 서버의 정책을 준수해야 하며, 과도한 요청은 제재의 원인이 될 수 있습니다.
