1. 프로젝트 개요
서원대학교 e-campus(LMS) 연동을 위한 TypeScript 기반 클라이언트 라이브러리 및 CLI 도구.
Fiddler 로그 분석을 기반으로 한 정밀한 학습 자동화(ElearningSession)와 고품질 데이터 추출이 핵심임.

2. 주요 진행 상황 및 완료 사항
- [인증] 레거시 암호화(encryptData) 및 tough-cookie 기반 세션 관리 안정화.
- [추출] 과목, 공지, 과제, 자료실 등 모든 강의실 데이터 파싱 로직 구현 완료.
- [e러닝] 고해상도 MP4 URL 추출 및 스트림 기반 안정적 다운로드 기능 구현.
- [자동화] ElearningSession 고도화:
    - 6단계 시퀀스(창 열기 -> 진입 -> 기록 시작 -> 랜덤 딜레이 기반 반복 기록 -> 상세 확인 -> 종료 패킷) 보장.
    - 실시간 학습 진행률(prgrRatio) 추출 및 상태 관리 로직 추가.
- [CLI] prompt-client.js 최적화:
    - 1~11번 인터랙티브 메뉴 및 목록 선택 기반 UX.
    - 실시간 로그 UI 제어 (입력 프롬프트 하단 고정).
    - 1분 주기 안내 및 특정 학습률(5%, 10%, 25%, 50%, 75%, 100%) 도달 시 푸른색 강조 알림.
    - 'status', 'clear', 'stop' 등 실시간 명령어 처리 지원.

3. 핵심 소스 구조
- src/ecampus/login.ts: 메인 클라이언트(EcampusClient), axios 세션 관리.
- src/ecampus/elearning.ts: ElearningSession 클래스, 진행률 추출 및 종료 패킷.
- src/ecampus/classroom.ts & courses.ts: HTML/JSON 파싱 엔진.
- prompt-client.js: 사용자 인터페이스 도구.
