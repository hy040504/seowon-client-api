1. 프로젝트 개요
서원대학교 e-campus(LMS) 연동을 위한 TypeScript 기반 클라이언트 라이브러리 및 CLI 도구.
사용자 시나리오 모사(Fiddler 로그 기반)를 통한 학습 인증 자동화와 강의 자료 추출이 핵심 기능임.

2. 주요 진행 상황 및 완료 사항
- [인증] 레거시 암호화(encryptData) 기반 로그인 및 tough-cookie 세션 관리 구현 완료.
- [추출] 과목 목록, 강의실별 공지/과제/자료실 목록 파싱 로직 안정화.
- [e러닝] 주차별 강의 목록 추출 및 고해상도 MP4 URL 분석/다운로드 기능 구현 완료.
- [자동화] ElearningSession 도입: Fiddler 로그 분석을 기반으로 한 6단계 학습 시퀀스(창 열기 -> 진입 -> 기록 시작 -> 랜덤 딜레이 기반 반복 기록 -> 상세 확인 -> 종료 패킷) 구현 완료.
- [CLI] prompt-client.js 고도화: 인터랙티브 메뉴(1~11번), 실시간 로그 UI 제어(Readline 커서 제어), 자동 종료 타이머 통합.

3. 핵심 소스 구조
- src/ecampus/login.ts: 메인 클라이언트(EcampusClient), 세션 및 인증 제어.
- src/ecampus/elearning.ts: ElearningSession 클래스, 학습 시퀀스 및 MP4 다운로드 로직.
- src/ecampus/classroom.ts & courses.ts: HTML 파싱 엔진.
- prompt-client.js: 사용자용 인터랙티브 CLI 도구.

4. 현재 프로젝트 상태
- Node.js 20+ 환경에서 안정적으로 동작.
- 주요 API 기능에 대한 유닛 테스트 및 통합 테스트 구성 완료.
- 깃허브 원격 저장소(hy040504/seowon-client-api)와 동기화 완료.
