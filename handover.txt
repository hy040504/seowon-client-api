[1. 프로젝트 개요]

서원대학교 e-campus(LMS)의 화면 흐름과 HTTP 요청을 TypeScript 코드로 다루기 위한 비공식 클라이언트 및 CLI 도구 모음입니다.

주요 기능:
- 로그인 encryptData 생성 및 쿠키 세션 유지
- 교과/비교과 과목 목록 조회
- 공지사항, 강의자료, 과제 목록 조회
- 강의자료 상세 fragment 분석 및 첨부 다운로드
- 이러닝 주차/차시 파싱, MP4 URL 분석, 영상 다운로드
- 이러닝 학습 기록 갱신과 자동 시청
- 현재 기간 내 미완료 이러닝 탐색
- 현재 제출 가능한 미제출 과제 목록/본문 조회
- 성적 공개 여부, 설문 게이트, 항목별 점수, 총점, 등급 조회
- Fiddler SAZ 패킷 기반 로컬 파서 검증

공식 LMS SDK가 아닙니다. 계정 정보, 쿠키, LMS HTML/SAZ 캡처, 다운로드 파일은 민감 데이터로 취급합니다.

[2. 실행 환경]

- Node.js 20+
- npm
- package.json: ESM 패키지("type": "module")
- TypeScript strict mode
- Windows PowerShell 기준으로 개발 및 검증

주요 환경 변수:
- SEOWON_ID: 로그인 아이디 또는 학번
- SEOWON_PASSWORD: 로그인 비밀번호
- DOWNLOAD_HIGH_WATER_MARK: 다운로드 버퍼 크기(KB), 기본값 1024

[3. CLI 도구]

1) npm run prompt:client

개별 API 응답과 파싱 결과를 직접 확인하는 진단용 CLI입니다.

지원 명령:
- login
- courses
- notices
- materials
- assignments
- classroom-resources
- elearning-lessons
- elearning-open
- elearning-mp4
- elearning-download
- elearning-watch
- help

2) npm run auto:manager

반복 작업을 처리하는 실사용 CLI입니다.

현재 메뉴:
1. 로그인 / 로그인 정보 갱신
2. 이러닝 일괄 다운로드 (전체 대기열 시각화)
3. 이러닝 순차 자동 시청 (고급 로그 제어)
4. 전체 교과목 미제출 과제 전수 조사
5. 전 과목 기간 내 미완료 이러닝 자동 시청
6. 현재 수행 가능한 전 과목 미제출 과제 목록
7. 현재 수행 가능한 과제 선택 및 상세내용 보기
8. 강의자료 다운로드 (일괄 + 첨부 분석/미리보기)
9. 교과 과목 전체 성적(등급) 조회
0. 종료

여러 항목 선택은 "1,2,3-5"처럼 쉼표와 범위를 지원합니다.

[5. 성적 조회 구현 상태]

성적 조회 흐름:
1. GET /crs/scoreLect/scoreOpenJson?crsCreCd=...
2. 공개 시간, 공개 여부, 설문 게이트 판정
3. POST /crs/creCrsLect/Form/classRoomMainForm with crsCreCd, mcd=""
4. GET /crs/scoreLect/Form/viewStdScore?crsCreCd=...
5. HTML hidden input에서 stdNo, crsCreCd 추출
6. POST /crs/scoreHome/viewStdScoreSumm with stdNo, crsCreCd
7. .tbl_container .tbl_item에서 항목명/값/총점/등급 추출

중요 포인트:
- viewStdScoreSumm 호출 전에 classRoomMainForm으로 강의실 컨텍스트를 먼저 생성해야 합니다.
- viewStdScore 자체가 아니라 후속 viewStdScoreSumm fragment에 실제 점수와 등급이 있습니다.
- 일부 과목은 성적 비공개, 설문 미완료, 평가 미실시 상태로 차단됩니다.
- 브라우저 화면에서는 등급이 보이는데 API 세션에서 비어 있으면 npm run capture:live로 실제 viewStdScoreSumm/viewStdScoreItem 응답을 다시 캡처해야 합니다.
- capture-live의 cookies 명령으로 현재 브라우저 쿠키를 .seowon-ecampus.cookies.json에 저장해 auto-manager에서 재사용할 수 있습니다.

주요 공개 API:
- client.getScoreOpenInfo({ crsCreCd })
- client.getScoreAccessInfo({ crsCreCd })
- client.getScore({ crsCreCd })
- client.getScorePageHtml({ crsCreCd })
- client.getScoreSummary({ crsCreCd, stdNo? })
- parseEcampusScoreOpenResponse()
- parseEcampusScoreSurveyResponse()
- parseEcampusScorePageHtml()
- parseEcampusScoreSummaryHtml()
- parseEcampusScoreSummariesFromSaz()

[6. 강의자료 구현 상태]

- getMaterialList는 목록 항목마다 상세 조회용 request 객체를 포함합니다.
- 실제 첨부는 /bbs/bbsLect/viewAtcl fragment에서 추출합니다.
- viewAtclForm은 shell 성격의 응답만 줄 수 있으므로 실제 본문/첨부 파싱에는 viewAtcl POST가 중요합니다.
- fileDown('TOKEN') 형태와 /file/download/TOKEN 형태를 모두 지원합니다.
- auto-manager 메뉴 8은 선택한 강의자료의 첨부를 미리 분석한 뒤 첨부가 있는 항목만 다운로드 큐에 넣습니다.
- 저장 경로는 downloads/<과목명>/강의자료들/<강의자료명>/ 입니다.

[7. 이러닝 자동 시청 상태]

ElearningSession 처리 순서:
1. lessonNewWindow 호출
2. viewLessonCmnt 호출
3. 최초 addStudyRecord 호출
4. 응답 prgrRatio를 서버 학습률 표시값에 반영
5. studyDetailId 확보
6. 첫 갱신은 25~35초 후
7. 이후 45~75초 간격으로 갱신
8. 각 갱신마다 누적 시간을 60초 단위로 증가
9. 갱신마다 viewLessonStudyDetail 확인
10. 종료 시 exitStudy 호출

auto-manager 메뉴 3/5는 watchLessonQueue에서 순차 처리합니다. TTY 환경에서는 3줄 고정 상태 영역을 사용하고, NO_COLOR가 있으면 색상 효과를 비활성화합니다.

[8. auto-manager 최신 동작]

세션:
- 시작 시 .seowon-ecampus.cookies.json을 불러옵니다.
- 유효한 쿠키가 있으면 기존 세션을 재사용합니다.
- 작업 중 SESSION_EXPIRED 또는 로그인 관련 오류가 나면 저장 계정/.env로 재로그인 후 원래 작업을 한 번 재시도합니다.

이러닝:
- 메뉴 2는 선택 차시를 병렬 다운로드합니다. 동시 다운로드 수는 1~5로 제한합니다.
- 메뉴 3은 선택 차시를 순차 자동 시청합니다.
- 메뉴 5는 전 과목에서 현재 기간 내 "학습중(지각)" 또는 "미학습(결석)" 차시를 찾아 자동 시청합니다.

과제:
- 메뉴 4는 교과 과목 전체에서 미제출/진행중 과제를 조사합니다.
- 메뉴 6은 현재 제출 기간 안에 있고 아직 제출 완료되지 않은 과제를 전 과목에서 찾습니다.
- 메뉴 7은 메뉴 6과 같은 조건의 과제를 선택해 상세 HTML에서 "과제내용" 영역의 .note-editable만 출력합니다.

성적:
- 메뉴 9는 getCourseGroups().curricular에 포함된 교과 과목만 순회합니다.
- 각 과목에서 client.getScoreSummary({ crsCreCd })를 호출해 등급만 요약 출력합니다.
- 조회 불가 상태는 [SKIP]과 사유로 표시합니다.

[9. 주석과 문서화 기준]

- 모든 함수는 한국어 JSDoc을 유지합니다.
- JSDoc에는 @param, @returns를 작성하고, 예외가 발생할 수 있는 함수에는 @throws를 작성합니다.
- 일반 주석은 코드가 무엇을 하는지가 아니라 왜 필요한지를 설명합니다.
- 서버 API 제약, LMS HTML 구조 의존성, 터미널 렌더링 보정, 세션 흐름처럼 맥락이 필요한 부분에만 짧게 주석을 둡니다.
- 중복 설명이 필요해 보이면 먼저 함수명, 변수명, 구조를 개선하는 방향을 우선합니다.
- 2026-07-02 기준 src, auto-manager.ts, prompt-client.js, scripts의 named function/method JSDoc 누락 스캔 결과는 0건입니다.

[12. 유지보수 주의사항]

1) 성적 조회
- 실제 점수/등급은 viewStdScoreSumm fragment에서 추출합니다.
- classRoomMainForm 진입 없이 viewStdScoreSumm만 호출하면 평가 미실시 또는 빈 fragment가 나올 수 있습니다.
- 성적 공개/설문/평가 상태는 과목별로 다릅니다.

2) 목록 페이지 크기
- 일부 LMS 목록 API의 기본 listScale은 10입니다.
- 항목이 많은 과목은 listScale 확대 또는 페이지 처리 보완이 필요할 수 있습니다.

3) 쿠키 유효성
- isCookieJarUsable은 만료되지 않은 쿠키 존재 여부를 봅니다.
- 실제 서버 세션 생존 여부는 후속 요청에서 판별됩니다.

4) LMS HTML 구조 변경
- 과제 상세는 label.label-title="과제내용"과 .note-editable 구조에 의존합니다.
- 강의자료 첨부는 viewAtcl fragment와 fileDown 구조에 의존합니다.
- HTML 템플릿 변경 시 selector 보완이 필요합니다.

5) 민감 데이터
- 실제 계정, 쿠키, 세션, SAZ, HTML 캡처, 다운로드 파일은 커밋하지 않습니다.
- files/, captures/, downloads/, test/는 로컬 검증 자료로 취급합니다.
