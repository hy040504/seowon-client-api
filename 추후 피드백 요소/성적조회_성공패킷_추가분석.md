# 성적조회 성공 패킷 추가 분석 메모

## 현재 반영된 실패 패킷 기준

- 확인 패킷: `files/성적확인 실패 패킷.saz`
- 성적 공개 여부 API: `GET /crs/scoreLect/scoreOpenJson?crsCreCd=...`
- 실패 원인:
  - `returnVO.scoreOpenYn === "Y"`
  - `message < returnVO.scoreOpenDttm`
  - 예: `message: "20260701023857"`, `scoreOpenDttm: "20260701090000"`
- 프론트 메시지:
  - `성적 조회 기간이 아닙니다.`
- 현재 코드 반영 위치:
  - `src/ecampus/score.ts`
  - `EcampusClient.getScoreOpenInfo()`
  - `EcampusClient.getScoreAccessInfo()`
  - `EcampusClient.getScorePage()`
  - `EcampusClient.getScorePageHtml()`

## 성공 패킷을 받으면 확인할 항목

1. `scoreOpenJson` 성공 조건
   - `message >= returnVO.scoreOpenDttm`
   - `returnVO.scoreOpenYn === "Y"`
   - `returnVO.scoreViewReschYn` 값이 `Y`인지 `N`인지 확인

2. 설문 게이트가 있는 경우
   - 호출 API: `GET /crs/scoreLect/cheeckStdReshJoin`
   - 확인 필드:
     - `result`
     - `returnVO.reschJoinYn`
     - `returnVO.reschDttmYn`
   - 분기:
     - `reschJoinYn === "N" && reschDttmYn === "N"`: 설문 기간 종료
     - `reschJoinYn === "N"`: 설문 참여 필요
     - 그 외: 성적 페이지 진입 가능

3. 실제 성적 페이지 응답 형식
   - 예상 호출: `GET /crs/scoreLect/Form/viewStdScore?crsCreCd=...`
   - 성공 패킷에서 확인할 것:
     - 응답이 HTML인지 JSON인지
     - 점수 항목 테이블 selector
     - 총점, 등급, 출석/과제/시험 등 세부 항목 필드명
     - 개인정보 또는 학번이 포함되는 위치
   - 성공 응답 구조가 확인되면 `parseEcampusScorePageHtml()` 같은 별도 파서를 추가한다.

## 현재 의도적으로 남겨둔 제한

- 성공 패킷이 아직 없어 실제 성적 테이블 파서는 만들지 않았다.
- 현재 `getScorePage()`는 접근 가능할 때 HTML 원문을 반환하는 수준이다.
- 성공 패킷이 들어오면 HTML 구조를 기준으로 타입을 추가한다.
  - 예: `EcampusScoreItem`, `EcampusScoreSummary`, `EcampusScorePage`

## 추가 구현 후보

- `parseEcampusScorePageHtml(html)` 추가 완료
- `getScore({ crsCreCd })` 고수준 메서드 추가 완료
- `parseEcampusScorePageFromSaz(saz)` 추가 완료
- README 사용 예시 추가 완료

## 성공 패킷 반영 결과

- 확인 패킷: `files/성적확인 성공 패킷.saz`
- 성공 조건:
  - `scoreOpenJson.returnVO.scoreOpenYn === "Y"`
  - `message >= scoreOpenDttm`
  - 설문 게이트 없음: `scoreViewReschYn`은 `N` 또는 빈 문자열로 내려옴
- 실제 점수 데이터 위치:
  - `GET /crs/scoreLect/Form/viewStdScore?crsCreCd=...`
    - 전체 성적 화면 HTML
    - hidden input: `stdNo`, `crsCreCd`
  - `POST /crs/scoreHome/viewStdScoreSumm`
    - body: `stdNo`, `crsCreCd`
    - 실제 요약 fragment
    - selector: `.tbl_container .tbl_item`
    - 항목명: `.title`
    - 값: `.text`
- 구현 반영:
  - `parseEcampusScoreSummaryHtml(html)`
  - `parseEcampusScoreSummariesFromSaz(saz)`
  - `EcampusClient.getScoreSummary()`
  - `EcampusScoreItem`, `EcampusScoreSummary`, `EcampusScoreSummaryCapture`
